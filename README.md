#Calligram

Inspired by Arabic calligrams and Guillaume Apollinaire’s Poems of Peace and War, this project was created as a digital ode to visual poetry. I wanted to write an ODE to Apollinaire, but _I found myself stuck in the cube_.

This is my first project using the Pygame library.
To run it, clone the repository and execute:
```bash
python main.py
```
You can customize the color (I used hot pink because it found it nice, and I hope you find it pleasing too) and even modify the text line.
(Don’t forget to add a space at the end!)
